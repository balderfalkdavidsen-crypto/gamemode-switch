Gamemode Switch (client-side Fabric mod)
Build:  1) Install JDK 25   2) Edit gradle.properties (fabric_api_version, loom_version)
        3) gradle wrapper --gradle-version 9.4.1   (once)   4) ./gradlew build
Jar:    build/libs/gamemode-switch-1.0.0.jar  (NOT the -sources jar)
Needs cheats/operator permission to change gamemode.
